**One-liner:** Mario Kart Wii, recompiled to run natively on the PlayStation 3. No emulator.

**Short description:** MKW PS3 is a native port of Mario Kart Wii to the PS3, built on the
WiiCompiled static recompiler. The game's code is translated to C++ ahead of time and compiled
for the Cell, with the Wii's graphics, audio and system software rebuilt on the PS3 side. You
build it from your own PAL copy of the game with one command, and install it like any other
homebrew package.
